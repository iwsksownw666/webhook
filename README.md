#About This Project Being Open Source
Someone asked me if this script could be open-sourced.

My answer: since someone wants it, I'll just open-source it.

So here we are.

A Few Things to Clarify
This script has never been open-sourced before.

Before it landed here, it was just something I used myself. It was never released, and nobody else has ever open-sourced it. If you see something similar floating around online, that's someone else's business — nothing to do with this.

The code is posted as-is.

No cleanup, no refactoring, no proper docs. It works, but it's not polished. Feel free to tweak it yourself if that bothers you.

No maintenance guaranteed.

I open-sourced it so people who need it can have it. That doesn't mean I'll keep updating it, answering questions, or taking feature requests. You can open an issue, but I might not reply.

Anyway
It's here. Take it and use it.
