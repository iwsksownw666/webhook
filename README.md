<b>A Few Things to Clarify</b>
<font size="5"><b>This script has never been open-sourced before.</b></font>

<font size="5"><b>The code is posted as-is.</b></font>

<font size="5"><b>No cleanup, no refactoring, no proper docs. It works, but it's not polished. Feel free to tweak it yourself if that bothers you.</b></font>
