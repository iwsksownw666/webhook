A Few Things to Clarify
<font size="5">This script has never been open-sourced before.</font>

<font size="5">Before it landed here, it was just something I used myself. It was never released, and nobody else has ever open-sourced it. If you see something similar floating around online, that's someone else's business — nothing to do with this.</font>

<font size="5">The code is posted as-is.</font>

<font size="5">No cleanup, no refactoring, no proper docs. It works, but it's not polished. Feel free to tweak it yourself if that bothers you.</font>
